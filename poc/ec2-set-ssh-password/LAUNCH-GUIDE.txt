📍 MANUAL BROWSER ACCESS
════════════════════════════════════════════════════════════════════

If browser doesn't auto-open, navigate to:

   http://localhost:3000


🛑 STOPPING THE SERVER
════════════════════════════════════════════════════════════════════

Press: Ctrl + C

(Server will shut down gracefully)


💡 TIPS
════════════════════════════════════════════════════════════════════

• Use ./run.sh for quickest launch
• All methods achieve the same result
• Server runs on port 3000 by default
• Change port: PORT=8080 ./run.sh


🔧 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════

Browser didn't open?
   → Open manually: http://localhost:3000

Port 3000 in use?
   → Change port: PORT=8080 ./run.sh

Node.js not found?
   → Install from: https://nodejs.org/


📚 NEXT STEPS
════════════════════════════════════════════════════════════════════

After launch:

1. Choose setup mode (Existing Instance or User Data)
2. Enter root password
3. Upload PEM key (for existing instance)
4. Enter EC2 details
5. Click "Setup Password"
6. Watch real-time logs
7. Login: ssh root@your-ec2-ip
